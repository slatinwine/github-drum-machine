# 代码鼓机 · 听见你的提交频率

输入一个 GitHub 仓库地址，查看它近三个月的提交砖块图，再把每日提交变成鼓点节奏——一周是一拍，周一到周日各对应一件乐器，提交越多鼓点越响。

## ✨ 功能特性

- 输入 `github.com/用户名/仓库名`，调用 GitHub 公开 API（无需登录）拉取近 91 天提交并按天计数
- 提交砖块图：颜色深浅表示当日提交量，播放时当前周的整列高亮闪动
- Web Audio 合成鼓点：底鼓 / 军鼓 / 踩镲 / 拍手 / 嗵鼓 / 边击 / 镲片对应周一至周日，当日提交越多力度越大（连续多次提交变成重音）
- 速度（90–400 BPM）与音量实时可调
- 分享链接：节奏数据编码进网址，对方打开直接播放，无需重新请求 GitHub
- 导出 WAV 音频文件，可发给他人或留档

## 🚀 使用方法

无需构建，直接用浏览器打开 `index.html`（查询仓库需联网；GitHub 匿名 API 每小时限 60 次，超限会提示稍后再试）。

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript（单文件）
- GitHub REST API（公开 commits 接口）、Web Audio API（实时播放 + `OfflineAudioContext` 渲染 WAV）

## 📁 目录结构

- `index.html` — 页面、数据拉取、鼓机播放与导出逻辑
- `qrcode.jpg` — 页脚展示的公众号二维码图片
